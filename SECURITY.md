# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
| ------ | --------- |
| 0.1.x  | Да        |
| < 0.1  | Нет       |

## Как сообщить об уязвимости

Не создавайте публичный issue для уязвимостей. Используйте приватный
security advisory в GitHub: вкладка **Security → Report a vulnerability**.
Укажите версию, вектор атаки и минимальное воспроизведение.

Мы подтвердим получение в течение 72 часов и согласуем срок раскрытия.

## Область ответственности

- Sweety не санитизирует HTML в `Popup`, `Tooltip` и атрибуции. Передавайте
  только доверенный контент или очищайте его на стороне приложения.
- Загрузка тайлов и GeoJSON выполняется приложением; библиотека не делает
  сетевых запросов, кроме изображений тайлов по переданному шаблону URL.
- CSP и CORS настраиваются на стороне сервера и приложения.
