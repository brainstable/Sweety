Каталог подложек

Панель в правом верхнем углу карты открывает превью, поиск и категории. Смена подложки сохраняется в localStorage.

A. Manager

`basemaps.install(map).set(id)`

—

Вариант и retina

`setVariant('retina')` и `set(id, { variant })`

Ключ Mapbox

Ключ хранится только в памяти. Без ключа будет basemaperror.

B. Без manager

`createBasemap(id).addTo(map)`

C. Control

Панель уже добавлена: `new BasemapControl({ preview: true })`.

D. Map options

`new Map('map2', { basemap: 'carto-dark' })` через init hook.
