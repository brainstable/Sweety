Редактор геометрии

Выберите «Редактировать», затем объект — появятся вершины. Тяните вершины, середины сегментов или тело фигуры. Изменения пишутся в журнал.

Shift — мультивыбор Enter / двойной клик — завершить Esc — отменить вершину/черновик Ctrl+Z / Ctrl+Shift+Z — undo/redo ПКМ по вершине — удалить её Кнопка «Перетаскивать» — перемещение тел без правки вершин Вторая группа кнопок — мультиобъект, границы, отверстие и разрез
