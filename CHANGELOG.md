# Changelog

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Плагин редактирования: мультиобъекты — объединение выбранных полигонов или
  линий в один слой (`MultiPolygon` / `MultiLineString`) и обратное
  разъединение на отдельные объекты. Методы `mergeSelected`, `explodeSelected`,
  `canMerge`, `canExplode` и события `merge`, `explode`, `*:invalid`.
- Плагин редактирования: отверстия в полигонах — рисование (`startHole`),
  добавление и удаление кольца (`addHole`, `removeHole`) с проверкой вложенности
  и пересечения границ, события `hole:added`, `hole:removed`, `hole:invalid`.
- Плагин редактирования: разрезание объектов секущей линией (`startCut`,
  `cutLayers`) — полигон делится на две части, полилиния на части, отверстия
  делятся вместе с полигоном.
- Плагин редактирования: объединение полигонов по общим границам
  (`unionSelected`, `canUnion`) — растворение общей границы с сохранением
  отверстий; наложение объектов распознаётся и отклоняется.
- Новые кнопки панели редактора (мультиобъект, объединение по границам,
  разъединение, отверстие, разрез) с включением по текущему выбору, иконками и
  строками i18n.
- Плагин редактирования: режим перетаскивания — `enableDrag`/`disableDrag`/
  `toggleDrag`/`canDrag`, настройка по слою (`enableLayerDrag`,
  `disableLayerDrag`, `layer.options.draggable`), опция `drag` и события
  `drag:start`, `drag`, `drag:end`, `drag:enabled`, `drag:layer`.
  Тело объекта двигается без выделения одной командой отмены.
- Плагин редактирования: опции `removeVertexOn` (правый клик, клик, двойной клик
  или ничего), `removeLayerBelowMinVertexCount`, `hideMiddleMarkers` и метод
  `toggleEdit`. Отверстие удаляется по вершинам целиком, не трогая полигон.
- Плагин редактирования: короткое сообщение об отказе операции (пересекающиеся
  полигоны, линия не пересекает границу дважды, отверстие вне полигона) и
  строки i18n для этих причин.
- Ядро: `Polygon.toGeoJSON()` группирует кольца по вложенности и отдаёт
  `MultiPolygon` для нескольких несвязанных контуров, а не `Polygon` с мнимыми
  отверстиями. Новая утилита `geo/rings.js`.
- Бесплатные подложки `esri-light-gray` и `esri-dark-gray` (Esri Gray Canvas):
  светлый и тёмный стили без ключа, до 16 уровня зума.
- `BasemapControl`: опции `labels` (свои подписи провайдеров) и
  `previewCoords` (тайл-образец для превью), кнопка закрытия в заголовке панели.

### Изменено

- Плагин редактирования: `Polygon.toGeoJSON()` может вернуть `MultiPolygon` для
  полигона из нескольких контуров — это изменение поведения для тех, кто
  разбирал кольца по индексу. Отверстия и один контур по-прежнему дают `Polygon`.
- Плагин редактирования: удаление вершины ниже минимума теперь убирает кольцо
  или объект (по умолчанию), а не молча ничего не делает; вернуть прежнее
  поведение можно опцией `removeLayerBelowMinVertexCount: false`.
- Панель подложек стала списком: заголовок, строки с превью 64×46, одно название
  без лишних метаданных, галочка у активного стиля. На узких экранах панель
  открывается листом снизу.
- Демо подложек упрощено до полноэкранной карты и одного выбора стиля: семь
  бесплатных подложек с русскими названиями, без сайдбара с примерами API.

### Исправлено

- Объединение полигонов по границам: объект, целиком лежащий внутри другого,
  больше не превращается в отверстие, а остров внутри отверстия остаётся
  отдельным контуром результата.
- Разрезание: привязка при рисовании секущей больше не прилипает к вершинам
  разрезаемых объектов, из-за чего разрез молча отменялся.
- Части разреза и разъединения не наследуют `feature.id`: одинаковые
  идентификаторы ломали стили и повторный импорт у потребителей GeoJSON.
- Если превью подложки не загрузилось, остаётся цветная заглушка с буквой,
  а не пустой серый квадрат.
- Документация в браузере: `README.md`, `docs/*.md` и `CHANGELOG.md` в dev-сервере
  теперь отдаются как HTML-страницы с `charset=utf-8`, навигацией и подсветкой
  таблиц и блоков кода. Устранены «кракозябры» при открытии документации из демо.

## [0.1.0] — 2026-11-15

Первая публичная версия Sweety: модульная картографическая библиотека без
runtime-зависимостей.

### Добавлено

- **Ядро карты**: `Map`, `Evented`, `Handler`, `LatLng`, `Point`, `Bounds`.
  Инициализация по id или `HTMLElement`, панели, `setView`, `panBy`, `panTo`,
  `flyTo`, `fitBounds`, `flyToBounds`, `getBoundsZoom`, `maxBounds`,
  ограничения зума и адаптация к размеру контейнера.
- **Проекции**: `Projection`, `CRS`, `Transformation`, EPSG:3857 и EPSG:4326,
  корректная обратная формула Меркатора и ограничение широты у полюсов.
- **Взаимодействия**: перетаскивание указателем с инерцией, зум колесом с
  debounce, двойной клик, pinch-зум двумя пальцами, CSS-анимация зума,
  `prefers-reduced-motion`.
- **Тайлы**: `TileLayer` с XYZ-шаблоном, субдоменами, TMS, retina `{r}`,
  `{-y}`, `maxNativeZoom`, кэшем изображений, повторами загрузки,
  `errorTileUrl` и виртуализацией видимых тайлов.
- **Маркеры**: `Marker` с `Icon` и `DivIcon`, draggable, клавиатурной
  активацией, z-index, прозрачностью, popup и tooltip.
- **Оверлеи**: `Popup` и `Tooltip` с HTML/DOM/функциональным контентом,
  позиционированием, авто-закрытием, Escape, auto-pan и событиями.
- **Векторы**: `Polyline`, `Polygon` с отверстиями, `Circle`, `Rectangle`,
  общий SVG-рендерер и Canvas-рендерер с hit-testing.
- **GeoJSON**: `GeoJSONLayer` с FeatureCollection, Feature, GeometryCollection,
  MultiPoint, MultiLineString, MultiPolygon, style-функцией, `pointToLayer`,
  `onEachFeature`, `filter`, `coordsToLatLng` и экспортом.
- **Группы**: `LayerGroup` и `FeatureGroup` с общими попапами, tooltip-ами,
  стилями и всплытием событий.
- **Контролы**: `ZoomControl`, `AttributionControl`, `ScaleControl`,
  `LayersControl` и кастомные контролы в четырёх углах.
- **Плагины**: `definePlugin`, `use`, `unuse`, реестр и `Map.addInitHook`.
- **Публичный API**: ESM- и UMD-сборки, namespace `Sweety`, JSDoc на русском,
  `sweety.css`.

### Производительность

- Виртуализация тайлов: в DOM только видимая область и `keepBuffer`.
- `requestAnimationFrame` для инерции, `flyTo`, `panTo`, Canvas и resize.
- `rafThrottle` для `mousemove`.
- Canvas-рендерер для больших наборов векторов, объединение кадров.
- LRU-подобный кэш изображений тайлов.
- Режим `updateWhenIdle` у `TileLayer`.

### Исправлено

- Единый счётчик `stamp` для слоёв, групп и event-parent: идентификаторы больше не
  пересекаются, если дочерние слои добавлены в группу раньше самой карты.
- Исправлен размер тайла: `Point(tileSize, tileSize)` вместо нулевой высоты,
  из-за которой тайлы не отображались в браузере.
- CSS-переход зума включается после первого кадра, поэтому анимация масштаба
  действительно запускается в браузере.
- Статистика демо обновляется после перетаскивания маркера.
- Начальный вид демо приближен до zoom 14, добавлен скриншот `docs/demo.webp`.

### Документация

- Русский README с быстрым стартом, API и примерами.
- `docs/API.md` — полный справочник.
- `docs/ARCHITECTURE.md` — архитектура, координатные системы, рендеринг.
- `docs/GIT-WORKFLOW.md` — ветвление, Conventional Commits, hooks, CI, релизы.
- `CONTRIBUTING.md`, `SECURITY.md`.
- Интерактивное демо `examples/index.html`: OSM, маркеры, полигон, GeoJSON,
  Canvas, скриншот `docs/demo.webp`.

### Тестирование

- 137 тестов Vitest + jsdom.
- Покрытие строк около 89%, функций — около 85%.
- Тесты геометрии, проекций, событий, карты, жестов, тайлов, маркеров,
  оверлеев, векторов, Canvas, GeoJSON, контролов, плагинов и публичного API.

### Инфраструктура

- Vite 8, ESM + UMD + CSS, source maps, минификация Oxc.
- ESLint, Prettier, Vitest, commitlint, husky, lint-staged.
- GitHub Actions: lint, format check, coverage, build, verify, `npm pack`.
- Шаблоны PR и issue, Dependabot, защита веток.

### Известные ограничения

- Нет SSR и WebGL.
- GeoJSON не репроецируется из произвольных CRS.
- HTML в попапах и tooltip-ах не санитизируется библиотекой.
- Для идеальной резкости при непрерывном `flyTo` требуются дробные тайлы,
  которые библиотека не загружает.
